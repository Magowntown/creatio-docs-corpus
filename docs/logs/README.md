# Session Logs

Chronological work history and test results.

## Files

| File | Purpose |
|------|---------|
| `SESSION_LOG_YYYYMMDD.md` | Daily session logs with all work done |
| `SESSION_HISTORY.md` | Overview of all sessions |
| `TEST_LOG.md` | All test execution results |
| `ACTION_LOG.md` | Historical action tracking |
| `ACTION_PLAN.md` | Original action plan |
| `CLAUDE_HISTORY.md` | Change history for CLAUDE.md |

## Latest Session

## How to Use

- Start each day by reading the latest session log
- Log all work to the current day's session log
- Log test results to `TEST_LOG.md`
