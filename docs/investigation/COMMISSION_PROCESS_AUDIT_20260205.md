## Finding 2: Subprocess Never Published

**Root cause:** `IWRecalculateCommissionOnOrderChangeV2` was never Published from the Process Designer.

| Flag | V2 Subprocess (BROKEN) | Working Process (BGBPOrderCalculateFieldsV2) |
|------|------------------------|----------------------------------------------|
| NeedUpdateSourceCode | **True** | False |
| NeedUpdateStructure | **True** | False |
| NeedInstall | **True** | False |
| IsChanged | **True** | False |

**Key distinction:**
- **Publish (Process Designer):** Validates, generates C# code, compiles, **registers start signals**, clears flags
- **Compile All (Configuration):** Only recompiles existing generated code — does NOT generate new code or register signals

**Fix:** Open V2 in Process Designer → click **Save/Publish**. This will:
1. Generate C# source code
2. Register signal subscriptions with the event system
3. Clear all NeedUpdate flags

**Fallback:** If V2 has validation errors preventing Publish, temporarily set V1 as Actual version (V1 was compiled when originally deployed from the package, monitors 11 columns).

### Commission Formula
```
IWSalesAmount = Order.Amount - Order.BGShippingCharge - Order.BGSalesTaxFloat
IWCommissionAmount = IWSalesAmount × (BGCommissionEarner.BGCommissionRate / 100)
```

```
Order changed → Subprocess → Pending → V4 recalculates → Done | Returned

```

## Finding 4: Recommended Recalculation Design (Option A)

After removing V4's "Payment Modified" signal (Step 11), add a Script Task to the subprocess:

```
Order product changed
  → ORDER: Calculated Fields V2 (updates Order.Amount/Tax/Shipping)
  → Subprocess V2 fires (Order Modified, filtered)
  → Sets all linked payments to IWCommissionStatus = Pending
  → Script Task loops through payments, invokes V4 per payment
  → V4 calculates, sets Status = Done
  → No recursion (direct invocation, not signal-based)
```

**Implementation requirements:**
1. Add `PaymentRecordId` input parameter to V4
2. Add OR condition to V4's ReadDataUserTask1 filter: `Id = [#PaymentRecordId#]`
3. Add Script Task to subprocess after "Set Pending" that calls V4 per payment via `ProcessEngineService`
